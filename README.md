A real-world Zomato/Swiggy-style Food Delivery Analytics project built using Microsoft SQL Server (MSSQL). 
The project analyzes customers, restaurants, menu items, orders, payments, deliveries, reviews, delivery partners, and restaurant offers to generate meaningful business insights and KPIs.

🔍 Project Highlights
Analyzed 100,000+ orders across multiple interconnected tables.
Performed data validation and quality checks.
Used INNER JOIN, LEFT JOIN, subqueries, EXISTS, NOT EXISTS, and CTEs.
Applied ROW_NUMBER(), RANK(), DENSE_RANK(), LAG(), and LEAD() for advanced analysis.
Performed revenue, order, customer, restaurant, cuisine, and delivery analysis.
Calculated important business KPIs such as Total Revenue, Total Orders, Average Order Value, Cancellation Rate, Delivery Success Rate, and Repeat Customer Rate.
Performed monthly, city-wise, cuisine-wise, and restaurant-wise analysis.
Analyzed customer behavior, restaurant performance, delivery efficiency, ratings, discounts, and offers.
Created reusable SQL Views and Stored Procedures for business reporting.

🛠️ Technologies Used
Microsoft SQL Server | SQL | SSMS | CTEs | Subqueries | JOINs | Window Functions | Views | Stored Procedures | KPI Analysis
